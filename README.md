# Generative AI Research Project

This repository contains the research materials for the study titled 
**"Using Generative AI Tools – Boon or Bane."**

## Project Structure

- **01_Literature_Review/** — Journal articles, conference papers, books, and newspaper articles related to the research topic.
- **02_Quantitative_Analysis/** — Survey data, survey questions, analysis scripts (Python, CSV, Excel files), and the survey analysis report.
- **03_Qualitative_Analysis/** — Interview transcripts, interview protocols, consent forms, analysis/insights reports, and data visualisations.
- **04_Drafts_and_Reports/** — Draft research proposals, conference papers, and final reports.
- **05_Additional_Materials/** — Information sheets, photos, and other supporting media files.

## Navigating the Repository

Each folder is organised by data type and stage of the research process. Files follow a consistent naming convention: `[ProjectName]_[DataType]_[Date]_[Number]`, allowing collaborators to quickly identify the content and purpose of each file without opening it.

## Contributing

Future collaborators should:
1. Clone this repository to their local machine.
2. Create a new branch before making any changes (use a descriptive branch name).
3. Commit changes with clear, meaningful commit messages describing what was changed.
4. Open a pull request for review before merging changes into the `main` branch.
5. Avoid uploading files containing identifiable participant information (e.g. consent forms, raw interview transcripts) without appropriate access controls in place.
